# Predictive Modeling Using Machine Learning

Build a machine learning model to predict outcomes using supervised learning.

## Algorithm Used
Random Forest Classifier

## Dataset
Iris Dataset

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Results
The model was trained successfully using the Iris dataset.
Accuracy was evaluated and a confusion matrix was generated for performance analysis.
